# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Rule conditions `min_size` and `max_size` (`"20KB"`, `"1.5GB"`; binary
  units, 1 KB = 1024 bytes, inclusive bounds).
- Rule conditions `source_url` (regex) and `source_host` (site or any
  subdomain), matched against the download URL and referring page that
  browsers record in the file's `Zone.Identifier` stream. The stream is only
  read for rules that use them. Dry-run output and the move log show the
  URL that matched.
- `tao log` shows recent move-log entries (`--limit N`), and
  `tao log --prune --older-than <duration>` removes failed moves and undone
  moves that undo and the watcher no longer need, with `--dry-run` and
  `--vacuum`. Moves that can still be undone are never pruned.
- MIT license, this changelog, a minimum supported Rust version
  (`rust-version = "1.90"`) and Dependabot updates for Cargo and GitHub Actions.
- CI runs on Ubuntu too (build, clippy, tests of the non-Windows fallbacks),
  checks the MSRV, and runs `cargo deny` (advisories, licenses, sources).
- README badges for CI status and the latest release.

### Changed

- The release workflow runs the whole CI suite first; a tag no longer
  publishes anything unless fmt, clippy and all tests pass. Release zips
  now include LICENSE and CHANGELOG.md.

## [0.1.3] - 2026-11-04

### Changed

- Releases now publish both `tao.exe` and `taow.exe`, and the workflow
  fails if the tag does not match the version in `Cargo.toml`.

### Fixed

- Clippy warnings in the tray icon code.

## [0.1.2] - 2026-11-04

### Added

- System tray mode for `tao watch`, and `taow.exe`, the windowless watcher
  that `tao install` registers to start at sign-in. The tray shows recent
  moves and has Sort now, Undo last move, Pause/Resume, Open config and Quit.
- Pixel-art tray icon (a ghost in a hat), generated by `assets/make-icon.ps1`.

### Fixed

- Release workflow output file path.

## [0.1.1] - 2026-11-04

### Added

- Release workflow: tagging `v*` builds the executables and publishes a
  zip with a SHA-256 checksum to GitHub Releases.

## [0.1.0] - 2026-11-04

### Added

- First release: `tao sort` (with `--dry-run`), `tao watch`, `tao undo`
  (with `--last N`), `tao install` / `uninstall` and `tao config`.
- TOML rules with `extensions`, `glob`, `regex`, `older_than` and
  `newer_than` conditions; first match wins.
- No-overwrite moves with ` (N)` suffixes, a SQLite move log written before
  each move, and skipping of partial downloads, hidden files and locked files.
- CI workflow (fmt, clippy, tests on Windows).
